# Prompt Templates That Actually Work

Stop reinventing the wheel. Here are battle-tested templates for the tasks you do most often.

## Email Templates

### Professional Response
```
Write a professional email response to: [paste email]
Tone: [friendly/formal/apologetic/enthusiastic]
Key point to convey: [your main message]
Length: [brief/moderate/detailed]
```

### Cold Outreach
```
Write a cold email to [role] at [company type].
Goal: [meeting/demo/partnership]
My value proposition: [what I offer]
Keep it under 150 words. No jargon. One clear CTA.
```

## Content Creation

### Blog Post
```
Write a blog post about [topic].
Audience: [who's reading]
Goal: [educate/persuade/entertain]
Tone: [casual/professional/technical]
Length: [word count]
Include: headers, examples, and a conclusion with CTA.
```

### Social Media
```
Create a [platform] post about [topic].
Hook: Start with something that stops the scroll.
Value: One clear takeaway.
CTA: [what should they do next]
Hashtags: 3-5 relevant ones.
```

## Analysis Templates

### SWOT Analysis
```
Perform a SWOT analysis for [company/product/idea]:
- Strengths: Internal advantages
- Weaknesses: Internal challenges
- Opportunities: External possibilities
- Threats: External risks
Be specific and actionable. No generic statements.
```

### Decision Matrix
```
I need to decide between [option A], [option B], and [option C].
Criteria that matter to me: [list criteria]
Weight each criterion by importance.
Score each option. Show a comparison table.
Recommend the best choice with reasoning.
```

## Developer Templates

### Code Review
```
Review this [language] code:
[paste code]
Check for: bugs, performance issues, security vulnerabilities,
readability, and adherence to best practices.
Suggest specific improvements with corrected code.
```

### Documentation
```
Write documentation for this [function/API/module]:
[paste code]
Include: purpose, parameters, return values, examples,
edge cases, and error handling.
Format: [JSDoc/README/API docs]
```
